# 月明·文案去 AI 味

审读已有中文稿件，清理机械连接、空泛修饰和模板表达，同时保留事实、原意与作者口吻。

## 你会得到什么

- 对应当前稿件的语言修改
- 更直接的因果、指代和转场
- 保留事实限定、案例与必要数据的成稿

## 试着这样说

```text
用 moonlit-de-ai-perception。把这篇稿件改得更自然。保留原意和事实，只清理空话、机械连接和无意义的修饰，不添加我没经历过的故事。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-de-ai-perception
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-de-ai-perception
```

## 配置与依赖

需要已有稿件及作者语气背景；本 Skill 本身无需额外 API Key。高频表达、结构问题与改写示例随包提供。适用于文章、小红书、X、朋友圈与视频脚本文字。

## 数据与使用边界

这是语言审读，不是事实核验或 AI 文本检测器，也不承诺检测分数。文本由当前 Agent 处理。早期参考来源见 [NOTICE.md](NOTICE.md)；公开版不打包上游原词表。
